Cloud Computing

Cloud computing means using computing resources such as servers, storage, databases and networking over the internet instead of owning and maintaining physical hardware. Companies and students rent only what they need and pay only for what they use, so they can start quickly without buying expensive equipment. The main benefits are flexibility, because resources can grow or shrink on demand, lower upfront cost, global availability, and easier maintenance since the provider takes care of the data centers. Today, many websites, apps and online services we use every day run in the cloud.

Cloud Services

IaaS

Infrastructure as a Service gives you virtual machines, storage and networks that you manage yourself.

Example: Amazon EC2

PaaS

Platform as a Service provides a ready environment to run your code, while the provider handles servers and updates.

Example: AWS Elastic Beanstalk

SaaS

Software as a Service delivers complete applications through a browser, with nothing to install or maintain.

Example: Google Workspace (Gmail)
